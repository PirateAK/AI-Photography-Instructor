## 3. NARRATION SCRIPT

**Welcome**

Film photographers had negatives and prints. Digital photographers have RAW files and finished images — and the same rule applies: the negative is sacred, the print is the interpretation. This lesson explains what a RAW file actually is, then walks one file through a restrained edit from start to finish.

**What RAW actually is**

A JPEG is a finished print: the camera develops it — applying white balance, contrast, sharpening, and compression — and throws the ingredients away. A RAW file is the ingredients: the sensor's nearly untouched readings, with room for you to make those calls instead. That's why RAW files look flat straight off the camera, why they're larger, and why software support varies by camera model and program — check that your editor reads your camera's files before committing to the format on a shoot.

**The restrained edit order**

Edit in this order, and stop when it looks right. One: exposure — overall brightness. Two: highlights and shadows — recover the sunlit sky, lift the shaded face, as far as the file's data allows. Three: contrast — the difference between light and dark that gives the photo shape. Four: color — white balance first, saturation last, and sparingly. Five: only then, local touches if the software offers them. Every step should survive the question: does this serve the photograph, or am I just turning knobs?

**Demonstration: one file, start to finish**

Here's a RAW file as the camera wrote it — flat, a little dull, honest. Exposure up slightly: the midtones land. Highlights pulled back: the sky's texture returns. Shadows lifted: detail appears in the dark jacket. Contrast nudged: the photo gains shape. White balance warmed a touch: the scene reads like the afternoon felt. Saturation: barely moved. Done. Two minutes of deliberate, small decisions — and the original file on disk has not changed by a single byte.

**Knowing when to stop**

The strongest edit is invisible. If a viewer notices your adjustment before your subject, you've gone too far. Compare against the original often — the before/after toggle is your conscience — and remember that a heavy edit cannot be un-noticed, while a restrained one can always be revisited.

**Learner practice**

Edit one RAW image using the restrained order, then compare it with the original. Write down each adjustment and the reason for it — reasons, not numbers, are the habit.

**Recap**

RAW is the ingredients; the JPEG was always a finished print. Edit in order — exposure, highlights and shadows, contrast, color — with small steps and the original untouched. Stop when it serves the photograph.

## 6. LEARNER PRACTICE

Edit one RAW image through the restrained order:

1. Exposure — set the overall brightness.
2. Highlights and shadows — recover what the file holds.
3. Contrast — give the photo shape.
4. White balance, then saturation — color last, lightly.
5. Compare with the original, write one line per adjustment explaining the reason, and stop.

If your camera shoots only JPEG: the same order and restraint apply to a JPEG edit — you'll simply have less latitude in highlights and shadows, which is itself the lesson about why RAW matters.

## 7. RECAP

RAW is the ingredients; JPEG is a finished print made by the camera's choices. Edit in order — exposure, highlights and shadows, contrast, color — with small, purposeful steps. The strongest edit is invisible, and the original file never changes.

## 8. ACCURACY CHECK

- RAW support varies by camera model and software version; verify the demonstrated file opens in the demonstrated program before filming.
- Software sliders, names, and layouts differ across editors; do not present one program's interface as universal.
- Do not promise specific recovery latitude from highlights/shadows — it depends on the camera, the exposure, and the scene.
- The order presented (exposure → highlights/shadows → contrast → color → local) is a dependable habit, not a mandatory sequence; say so if asked.
- If phone RAW (DNG) is mentioned, verify the capture and editing flow on the actual device before demonstrating.
