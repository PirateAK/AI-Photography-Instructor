# Intermediate Lesson 13 — Building a Consistent Editing Workflow

Class: Intermediate
Prerequisite: Beginner lesson on organization and editing; Intermediate lessons on RAW processing

## 1. LEARNING OUTCOME

By the end of this lesson, learners can follow a repeatable process from importing images to exporting and backing them up — and confirm that both original files and finished exports remain findable.

## 3. NARRATION SCRIPT

**Welcome**

Every photographer who has lost a card, overwritten a file, or spent an evening hunting for last month's keeper has learned this lesson the hard way. A workflow isn't bureaucracy — it's the difference between a library and a shoebox. This is the capstone habit of the Intermediate class.

**The five stages**

Import, organize, select, edit, export — and one habit riding on top of all five: backup. The names and software vary, but the stages don't. Beginner class introduced this arc; now we make it repeatable and add the safety net.

**Import and organize: findable beats clever**

Copy images from card or device into one consistent structure — a folder per shoot or per date, named so future-you can find it: "2026-10-12 harbor morning" beats "New Folder (7)." The exact method matters less than using it every time. Leave the card untouched until the copy is verified.

**Select and edit: reasons on record**

Review the set, mark the strongest candidates, and edit only those — with the restrained order from the RAW lesson: exposure, highlights and shadows, contrast, color. Originals stay untouched; every edit lives as a separate set of instructions or a copy. If you can't remember why a frame earned an edit, the selection criteria from Lesson 10 — focus, expression, composition, light, intent — are the checklist.

**Export and backup: two copies, one truth**

Export finished images as separate files in their own folder — full-resolution for printing, smaller copies for the web as needed. Then the habit that saves careers: a second copy of everything, originals and exports, somewhere else. An external drive, a computer-plus-cloud, any scheme — as long as it's automatic enough to actually happen and separate enough to survive one device's worst day.

**Demonstration: a small set, end to end**

Watch the whole pipeline on five photographs. Import from card to a dated folder. Organize: one folder, one clear name. Select: three favorites marked, reasons stated — the sharp one, the one with the light, the one that says the thing. Edit: one of the three, restrained, original untouched. Export: a copy into an "exports" folder. Backup: the whole dated folder copied to the external drive. Five stages, one small set, everything findable afterward — originals here, finished copies there.

**Learner practice**

Process a small photo set through the whole workflow and confirm two things at the end: you can find every original, and you can find every finished export.

**Recap**

Import, organize, select, edit, export — with backup riding over all of it. Consistency beats sophistication; findable beats clever. The originals are sacred, the exports are separate, and the second copy is the one that saves you.

## 6. LEARNER PRACTICE

Process a small photo set — five to ten images — through the full workflow:

1. Import into a dated, clearly named folder.
2. Organize and mark your three favorites, with one-line reasons.
3. Edit one, restrained, using the order from the RAW lesson.
4. Export a copy into a separate exports folder.
5. Back up the whole folder to a second location.
6. Then verify: find every original, find every export — without searching twice.

If you're using a phone: the same stages apply — the gallery is your import and organization, the favorites you starred are your selection, and the backup is simply confirming the photos also exist somewhere besides the phone.

## 8. ACCURACY CHECK

- Folder structures, backup tools, and export dialogs vary across operating systems and software; demonstrate only the setup shown, presenting the stages as the universal part.
- Do not claim any backup scheme is invulnerable — two copies in two places is the minimum habit, not a guarantee.
- Cloud backup behavior (sync delays, storage limits) varies; if mentioned, describe only what is shown.
- Verify that every demonstration folder and file name is legible on camera and matches the narration.
- The workflow's value claim (prevents lost files) is supported by the backup demonstration — do not skip it in filming.
